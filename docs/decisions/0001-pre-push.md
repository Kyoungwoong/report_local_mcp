# ADR-0001 — Git pre-push as an attempt signal

Decision: use a per-repository `pre-push` hook to record attempted ref updates without requiring an always-running MCP server. The hook is fast and fail-open. It does not prove success; later remote inspection reports `REMOTE_MATCH`, `REMOTE_MISMATCH`, or `UNKNOWN`, all of which describe current remote state rather than the push process exit status. Existing hooks and external/shared `core.hooksPath` locations are refused instead of overwritten or automatically chained. This prioritizes natural `git push` UX over exact success timestamps. Revisit a wrapper if precise post-push status becomes essential.
